Encomenda é **pedido pra uma data futura** — não é pra hoje. Use quando o cliente quer reservar produção pra um dia específico: aniversário, almoço de família, evento.

## Quando o cliente faz encomenda

- "Quero 2 picanhas pra sábado às 18h"
- "5 frangos pra domingo de manhã"
- "Combo da família pra almoço de terça"

A antecedência mínima padrão é **48 horas** (o admin ajusta esse número em Configurações).

## Passo a passo

1. Cliente acessa **casaroxa.com.br/encomenda** (link **Encomendar** no topo).
2. Vê os itens disponíveis agrupados por categoria (combos primeiro).
3. Escolhe quantidades.
4. Preenche **nome, telefone, data e hora desejada**. O calendário já bloqueia visualmente datas dentro da janela mínima.
5. Escolhe Retirada ou Delivery (com endereço).
6. Envia.
7. **Recebe imediatamente**:
   - Uma **página de acompanhamento** com status **Pendente**.
   - Uma **mensagem no WhatsApp** confirmando que recebemos a encomenda (se o aviso correspondente estiver ligado).

Daí em diante, é o admin que vai **aprovar ou recusar**.

## Pagamento de sinal

Se o admin pediu sinal ao aprovar, o cliente recebe um link no WhatsApp pra **pagar dentro do próprio site** (não precisa abrir outra aba nem ser redirecionado).

<BrowserFrame url="casaroxa.com.br/encomenda/abc123">
  <PixCheckoutScreen />
</BrowserFrame>

O cliente preenche o CPF, o sistema gera o **QR Code PIX** automaticamente e mostra ali mesmo, com botão pra copiar o código. A página fica olhando o pagamento sozinha — assim que cai, atualiza pra **"Recebemos seu sinal ✓"**.

<Callout kind="dica">
**Cliente sem CPF na hora?** Tudo bem — o pedido continua andando. A cobrança só é gerada no momento em que ele digitar o CPF na tela de acompanhamento.
</Callout>

## Receber a encomenda

Quando o admin marca como **Pronta**, o cliente recebe um WhatsApp:

- **Retirada:** "Pode vir buscar! 🛍"
- **Delivery:** "Estamos saindo pra entrega! 🛵"

A encomenda aprovada vira automaticamente um pedido na cozinha — o cliente consegue acompanhar o progresso de produção pelo mesmo link que ele tinha pra encomenda.
