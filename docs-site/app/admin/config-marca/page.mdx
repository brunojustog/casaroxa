A página de **Configurações** controla tudo que o cliente vê no site público — nome do negócio, número de WhatsApp, endereço, horários, banner promocional.

## Onde fica

**Ferramentas → Configurações**.

## O que tem pra mexer

| Campo | O que afeta |
|---|---|
| Nome do negócio | Topo do site, mensagens de WhatsApp, dados pra busca do Google |
| Slogan | Área principal da página inicial |
| WhatsApp | Botão "WhatsApp" no topo e código de acesso pro cliente |
| Endereço | Rodapé do site e dados pra busca |
| Horários | Rodapé |
| Instagram / Facebook | Rodapé |
| **Retirada habilitada** | Mostra (ou esconde) a opção de retirada no checkout |
| **Delivery habilitado** | Mostra (ou esconde) a opção de delivery + campo de endereço |
| **Pedido mínimo** | Valor mínimo aceito no checkout |

## Promoção em destaque (banner do topo)

Você pode configurar um **banner promocional** na página inicial preenchendo 5 campos:

- **Título** — o texto grande
- **Texto** — o subtítulo
- **Imagem** — endereço (URL) da imagem
- **Texto do botão** — ex.: "Ver combos"
- **Link do botão** — pra onde o botão leva (ex.: o cardápio na categoria Combos)

Se você preencher todos, o banner aparece. Se deixar vazio, fica o logo padrão.

## Histórico de mudanças

Toda alteração de configuração fica salva com **quem mudou e quando**. Útil pra auditar quando alguém pergunta "por que o WhatsApp tava errado ontem?".
